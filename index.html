Help — how PaperBoots works

The four documents

  • Change Order — Records a change to the job, what it costs (negative = credit back to the customer), how many days it adds or removes, and whether the customer approved it. The app keeps a running total of approved change orders for each job, printed right on the document so nobody argues about the number later.
  • Punch List — The walk-through fix-it list, organized by room or area. Mark each item Open → Done → Verified as you close it out. Completion percentage is calculated for you. Tap 📷 Photo on an item to take or pick a photo of the problem — it is shrunk to a small thumbnail, stored with the item on this device only, shown on the item, and printed on the walk-through sheet. The Photo ref field is still there if you also want to note a camera-roll file name (e.g., "IMG_2041").
  • Daily Log — The day's record: weather, crew on site, work performed, materials delivered, delays and visitors. These logs are what win (or settle) disputes months later.
  • Job Safety Assessment (JSA) — Pick the hazards for the task, write the controls and PPE for each, and have the crew sign off by name before work starts.

Working tips

  • Same job name = same job. Type a job name exactly the same way on every document and the app ties them together — change-order totals, search and the library all group by job name (capitals don't matter).
  • Duplicate as template — The Duplicate button copies a document so you can reuse its wording. Signatures are cleared, dates reset to today, punch items reset to Open, and change orders go back to Pending.
  • Signatures — Type the name in the signature box; it prints on the signature line in a script style. Have the customer sign the printed sheet as well if you want a wet signature for your files.
  • Printing — Print works from any saved document (Print button in the library or in the editor). Use your browser's "Save as PDF" if you want a file to text or email.
  • Your data stays on your device. Everything is stored in this browser on this phone/computer. Nothing is uploaded anywhere. Use Export backup in the library to save a copy, and Import backup to restore it on a new device.
  • Demo data — The app comes with one sample job ("Johnson Kitchen Remodel") with one of each document. "Clear demo data" in the library removes only those samples, never your real documents.

Known limits of this version

  • Punch-list photos: one photo per item, stored as a small thumbnail on this device only — it is never uploaded anywhere. The other document types do not take photos.
  • One device at a time — there's no cloud sync between a phone and an office computer. Export/import moves data manually.
  • Signature is a typed name rendered in script style, not a drawn signature.
